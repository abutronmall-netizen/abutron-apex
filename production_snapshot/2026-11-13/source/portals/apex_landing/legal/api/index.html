Broker account ownership

You must own or have valid authority to control every broker account you connect. APEX may use approved broker APIs or bridges subject to the broker's own rules. An APEX account is not itself a brokerage account and does not guarantee an active broker connection.

Credential protection

Never send broker passwords, API keys, access tokens or recovery codes through chat, email, or the registration form. Connect using an approved secure workflow when made available. Do not grant withdrawal permissions to a trading integration unless expressly necessary and separately approved; current DEMO registration does not request credentials.

Permitted use and rate limits

Do not flood APIs, bypass rate limits, impersonate other users, scrape confidential endpoints, manipulate market feeds or defeat security gates. Access can be throttled or suspended to preserve integrity. Documented rate-limit values, supported brokers and API specifications will be published if public API access is introduced.

Connectivity and loss

Tokens may expire and brokers may change methods, outages or trading restrictions. Network errors, sequencing failures, duplicate orders and inconsistent data may cause unexpected positions. The broker remains the authoritative record of orders and balances. Users must independently verify orders.

Revocation and incidents

Notify support@abutronfx.online of suspicious activity. Revoke credentials directly at the broker when needed and check open orders separately. We may disable a compromised integration. Current public registration creates no broker API access and no live execution rights.
