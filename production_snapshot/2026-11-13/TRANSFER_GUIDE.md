# How to transfer this branch into a NEW private repository

Requested destination: `abutronmall-netizen/abutron-apex-platform` (name is a proposed default, not a repo confirmed created).

The connected GitHub app can write files and branches but has **no create repository action**. Once a separate private repo is created under the same GitHub account, transfer the `production_snapshot/2026-11-13/` source folder and its manifests from this branch, then upload and review the PDF/DOCX documents separately. Do not merge this snapshot into production or expose customer data.

GitHub UI: Profile → Your repositories → New → name `abutron-apex-platform` → Private → Create repository. Return to ChatGPT with the repo URL to finish copying the source to its default branch.

Original private snapshot branch: https://github.com/abutronmall-netizen/abutron-apex/tree/snapshot%2Fproduction-source-2026-11-13
